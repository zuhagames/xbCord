INSTALLATION
Copy Plugins and xbCord to the root of your USB. Keep your existing xbCord.ini, token.bin and state.txt when updating. Do not replace a real token with the supplied placeholder token.txt.
For a manual upgrade from a loader installation, back up and replace the complete Plugins\xbCord folder so old slot-selection files are not carried over. Preserve the separate xbCord data folder. Using Settings > Updates handles the slots automatically.
Keep launch.ini pointing to Usb:\Plugins\xbCord\xbCord.xex. This file is now the loader. Copy the complete Plugins\xbCord folder, including slot-a; copying only the XEX will not install this build.
For a first sign-in, replace ALL placeholder text in xbCord\token.txt with only your complete current Discord token on one line, or use Type the token in xbCord. Keep the USB connected.

UPDATES
Open Settings > Updates > Check for updates. Select Download update when one is available. Wait for 'Update downloaded and verified', then restart the console when convenient. The loader tries the new slot at the next boot. Let xbCord finish startup for at least one minute before powering off.
The previous plugin slot remains available. If the trial does not finish startup, restarting again selects the previous version. An offline Discord account does not prevent startup confirmation. Never delete or modify slot metadata while updating.
To check developer releases, set update_channel=dev in your existing xbCord.ini. Use update_channel=beta for the beta channel. Automatic checking never forces a download or restart.

CONTROLS
In chats, servers or channels, click the left stick (LS) for Search and filter. Search matches names in the current list. Press BACK to toggle unread-only; B clears active filters before leaving the list.
Press START on a chat, server or channel to pin it. In Pinned, click LS to rename a shortcut or move it up/down. These names and ordering are saved locally for the signed-in account.
In an open chat, select one of your messages and press A for Edit message or Delete message. Deletion asks for confirmation. Other people's messages do not offer these actions.
Open Settings > Notification privacy to choose sender and preview, sender only, or New Discord message. Open Connection diagnostics from Settings or the sign-in screen to inspect network, authentication and verification results.

DEVELOPER TESTING
This updater installation requires testing on a physical Xbox before public use. Test a normal upgrade, cancel/back while downloading, a network interruption, and recovery after an unconfirmed first boot. Keep your previous complete installation on your PC for manual recovery.
If xbCord will not start, create an empty xbCord_off.txt at the USB root and restart. Remove it when ready to load xbCord again. For support, provide the build number and relevant xbCord.log or Plugins\xbCord\loader.log lines. Never share your token files.
