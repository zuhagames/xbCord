INSTALLATION
Copy Plugins and xbCord to the root of your USB. Keep your existing xbCord.ini, token.bin and state.txt when updating. Do not replace a real token with the supplied placeholder token.txt.
The plugin is Plugins\xbCord\xbCord.xex. Keep launch.ini pointing to Usb:\Plugins\xbCord\xbCord.xex. There is no separate loader or skin to install.
If upgrading manually, back up the old plugin and replace xbCord.xex with the one from this package. Preserve the separate xbCord data folder.
For a first sign-in, replace ALL placeholder text in xbCord\token.txt with only your complete current Discord token on one line, or use Type the token in xbCord. Keep the USB connected.

USB LAYOUT
Plugins\xbCord\xbCord.xex
xbCord\xbCord.ini
xbCord\token.txt

UPDATES
Open Settings > Updates > Check for updates. Select Download update when one is available, wait for the confirmation that xbCord.xex has been updated, then restart when ready.
The updater verifies the download before replacing the installed file. It keeps the previous plugin as xbCord\xbCord.previous.bin for manual recovery. If the console refuses to replace the file, copy xbCord.xex manually from the release ZIP. Account data and settings stay in place.
To check developer releases, set update_channel=dev in your existing xbCord.ini. Use update_channel=beta for the beta channel. Automatic checking never forces a download or restart.

UPGRADING FROM THE 0.2.0.1 DEVELOPER TEST
Use the test build's Settings > Updates to download 0.2.3 and restart. Let xbCord run for at least one minute; it will prepare the standalone plugin and ask for one more restart. After restarting again and finishing startup, the old managed slot folders are removed.
Keep the test build's slot-a folder until that upgrade has completed. If you deleted it already, install this 0.2.3 XEX manually instead.

CONTROLS
In chats, servers or channels, click the left stick (LS) for Search and filter. Search matches names in the current list. Press BACK to toggle unread-only; B clears active filters before leaving the list.
Press START on a chat, server or channel to pin it. In Pinned, click LS to rename a shortcut or move it up/down. These names and ordering are saved locally for the signed-in account.
In an open chat, select one of your messages and press A for Edit message or Delete message. Deletion asks for confirmation. Other people's messages do not offer these actions.
Open Settings > Notification privacy to choose sender and preview, sender only, or New Discord message. Open Connection diagnostics from Settings or the sign-in screen to inspect network, authentication and verification results.
In an open chat, click LS for chat options, including manual retry/discard of a failed message. Sending, sent, failed or unconfirmed delivery appears beside the message button. Retry asks for confirmation. Failed text is kept only briefly in a bounded memory buffer; drafts are not saved.
Press BACK in a chat to jump to unread messages; Y returns to the newest messages. The unread position must be available from Discord. Open Settings > Connection to see the live connection state or request a reconnect. Reconnect does not clear account verification requirements.

If xbCord will not start, create an empty xbCord_off.txt at the USB root and restart. To restore the previous plugin, copy xbCord\xbCord.previous.bin to Plugins\xbCord\xbCord.xex while the console is off. Remove the off file when ready to use xbCord again. This single-file layout does not automatically roll back a plugin that cannot start.
Keep a copy of your previous installation on your PC. Never share your token files.
